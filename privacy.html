Privacy Policy

Better Wishlist for Nintendo eShop · Effective 30 August 2026

The developer receives no personal data from the extension. It has no analytics, telemetry, advertising, background worker, or remote code.

The developer operates no server for this extension. Your settings stay in your browser, and the extension sends nothing to the developer.

What the extension does with your data

For Chrome Web Store disclosure purposes, the extension handles authentication information, website content, and the current supported Nintendo wishlist URL/storefront. Chrome Web Store policy includes data processed locally in its definition of data handling. This information is used only to provide the wishlist features described here. The developer cannot access it, and it is not used for advertising, profiling, or sale.

Nintendo

On supported Nintendo wishlist pages, the extension reads your wishlist and the related catalogue information from Nintendo so it can display your list with search, filters, and sorting.

On supported storefronts, it uses the sign-in session already open in the Nintendo page to authenticate wishlist requests sent to Nintendo. It does not persist session data in extension settings or send it to the developer.

The extension reads only the current supported wishlist URL and storefront locale needed to choose the regional behaviour. It does not read or retain broader browsing history.

When you confirm a removal, the extension sends that removal to Nintendo, in the same way the Nintendo page itself would. The extension asks you to confirm every removal.

Google Search

If you choose “Search reviews” on a game, a Google Search opens in a new tab containing that game’s title and, where known, its platform. This only happens when you click it.

Project links

The header and About link open the Chrome Web Store in Chrome or this project site in Firefox. The options page also links to the public repository on GitHub. The optional donation link opens Ko-fi. None of these links opens until you choose it.

Firefox data declarations

The desktop Firefox build declares authentication information, website content, website activity, location information, and search terms. These refer to the Nintendo session tokens, wishlist requests and confirmed removals, storefront country, and Google review searches described above. The extension does not access GPS location, transmit your local wishlist filter text, or send data to the developer. Firefox asks for consent to these required transmissions when you install the signed extension.

What is stored on your device

The extension saves these settings in your browser:

  • Extension settings are stored in your browser’s extension storage as nwm_settings_v1_showCrossRegion, nwm_settings_v1_saleUrgencyDays, and nwm_settings_v1_theme.
  • Your filter and sort choices are stored per site origin, in its own localStorage, under nwm_preferences. Because this storage is tied to the site, Europe and the Americas stay separate; Americas locales on www.nintendo.com share these preferences.

The extension does not transmit these values to the developer or any third party.

Permissions

The storage permission lets the extension remember your settings between visits. Its site access is limited to the supported Nintendo wishlist addresses. It has no background worker and does not download or execute code from the internet.

Third parties

Nintendo, Google, GitHub, and your browser each handle data under their own privacy policies when you use the relevant page, search, or link. This policy covers only the extension itself.

Children

The extension runs on a Nintendo page you are already signed in to. The developer receives no personal information from anyone, including children.

Changes

If this policy changes, the revised version will be published on this page with a new effective date. Material changes will also be noted in the extension’s changelog.

Contact

For privacy questions, bug reports, or other help, open an issue on the public project tracker.
